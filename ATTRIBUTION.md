# Attribution

WaW Launcher is an unofficial community application by [phil81334](https://github.com/phil81334).

Its tool commands and workflows follow Treyarch's original World at War Modtools Launcher, originally credited to Mike Denny and the Treyarch PC programming, production and modding teams. The original executables and game assets are not included; users supply their own installation.

The shared interface and cube icon follow Phil's WaW app family. The desktop framework is [Tauri](https://tauri.app/), with [Vite](https://vite.dev/) for the JavaScript build.

This application is not affiliated with Treyarch, Activision or UGX.
