About WaW Launcher

      

        
An unofficial tool made for the World at War modding community.

        

          Compile levels, build mods and open the Modtools applications. Uses
          your installed tools and the original Launcher's build workflow, with
          fixes for confirmed Launcher bugs.
        

        

          Requires World at War with Modtools already installed. It does not
          install patches or replace the compilers. Companion applications are
          optional and are launched from the game folder.
        

        

          Independent of Treyarch, Activision and UGX. Built with JavaScript,
          Vite, Rust and Tauri. Original Modtools and Launcher by Treyarch; see
          ATTRIBUTION.md.
        

        
Created by phil81334.
